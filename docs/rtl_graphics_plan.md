# 图形流水线 RTL 分阶段实施

本页记录图形硬件的接口边界、推进顺序和已验证范围。功能行为仍以
[GPU](gpu.md)、[Geom](geom.md)、[Rast](rast.md)、[Tex](tex.md)、
[ROP](rop.md)及[数值契约](numerics.md)为准；未实现阶段不得由C++算法
代替后标称为RTL端到端执行。

## 数据与控制路径

```text
host/CP命令与资源 → 共享Mem
       ↓
Vfetch/Pa → VS Shader → Clip/Vp/剔除 → ScreenTriangle
       ↓
Rast覆盖 → 重心边值 → 深度/透视属性插值 → Fragment
       ↓
Tex采样 → FS Shader/丢弃 → ROP深度/模板/混色 → 共享Mem附件
```

跨阶段传输使用单项`valid/ready`握手：`valid && ready`的时钟沿转移一个
完整记录；背压期间载荷和`valid`保持稳定。三角形输入必须在接受前完成
描述符与容量检查。片元按三角形顺序、内部按y/x顺序提交；清除与渲染
不得越过前一命令，深度/模板/颜色操作先读旧值并检查完整片元后写入。
存储仲裁必须对同一字节规定顺序，不得把现有`helo_memory`的主机/单数据
双端口当成多客户端总线。异常锁存到复位或任务替换，已提交的先前片元保留。

## 阶段与验收

| 顺序 | RTL边界及主要工作 | 当前状态 | 接入门槛 |
| --- | --- | --- | --- |
| 1 | `helo_rast_coverage`：Q4屏幕三角形→有序(x,y)、Q8边值/面积 | 已实现 | 共享边、绕序、裁界、退化、随机差分、背压/复位和`-Wall` lint |
| 2 | Rast属性插值：边值/面积与三个顶点→binary32深度、透视校正颜色/UV | 部分实现：Q16深度、逐顶点RGBA8颜色与Q16透视UV；缺完整FP32数值域 | 数值配置明确后按[数值契约](numerics.md)比对透视分母、深度和特殊值 |
| 3 | ROP片元：附件布局、深度/模板、颜色混合与顺序写回 | 部分实现：打包RGBA8、深度/模板及整数UNORM8 source-over混色；缺FP32颜色量化和清除 | 已有状态矩阵、非法描述符无副作用和内存差分；仍需完整颜色输入与清除 |
| 4 | Tex采样：描述符验证、nearest/双线性、wrap与统一存储请求 | 部分实现：Q16 UV的RGBA8 nearest、clamp/repeat和单数据端口共享读取；缺双线性及FP32坐标 | 边界和四邻域结果对照`tex_test`，内存更新立即可见 |
| 5 | Geom前后段：Vfetch/Pa、齐次裁剪、视口映射与剔除 | 未实现 | 复用`geom_test`，先确定非有限输入/裁剪输出容量和舍入规则 |
| 6 | CP与Shader、存储仲裁、图形ABI及GPU顶层连接 | 未实现 | 首先无Shader的不透明图元端到端，再运行真实VS/FS与`gpu_render_test`；不得跳过多lane/FPU依赖 |

顺序是验证与接口收敛次序，不强制物理流水级数。当前受限绘制路径在
Q4/Q16数值域内增加深度、颜色和UV插值，不代表通用片元或完整ROP；
第六阶段之前不能称为完整GPU RTL。每阶段均注册CTest、固定种子差分与独立
Verilator lint，失败不得使用空DUT或扩大颜色容差掩盖离散差异。

`helo_flat_draw`将Q4覆盖、Q16深度/透视UV与逐顶点RGBA8颜色插值、
RGBA8最近点纹理采样、单片元ROP及共享内存串接；源颜色可为平面
RGBA8或逐顶点透视校正RGBA8，纹素按通道执行
`(color*texel+127)/255`舍入，支持可选打包RGBA8 source-over混合。
深度比较固定为LESS，深度写和颜色写开启；模板关闭。纹理与ROP按片元
串行共用单个数据端口，纹素在该片元ROP测试前读取。图元入口预检附件和
启用的纹理布局、插值参数，零覆盖图元也不会绕过布局错误。不处理
Geom、图形Shader、完整FP32颜色、双线性过滤、命令包或清除。
覆盖与片元计数、非法附件布局锁存错误及复位恢复在
`flat_draw_compare_test_rtl`中与C++ Rast→Tex→Rop链路比对。

## 覆盖单元 v1 接口

`hw/rtl/rast/helo_rast_coverage.v`接收三个20位有符号Q4坐标与16位
目标宽高。坐标值n代表n/16像素，范围[-32768,32767.9375]；目标宽高
可为0至65535。扫描一个包围盒候选像素每周期最多一次，内部按正面积
绕序统一边方向，像素中心为(x*16+8,y*16+8)。负数包围盒使用向下/向上
整除，而非截零；边上只接受`dy<0 || (dy==0 && dx>0)`。

输出`out_edge0..2`与`out_area`是以Q4坐标相乘得到的非负Q8整数，
在有效片元上三条边值之和等于正面积。它们是后续插值的分子，不是
归一化float重心权重。`start_ready`只在空闲且未复位时有效；零面积、
零尺寸和完全不可见三角形不产生片元，仍给出一次`done`脉冲。`done`
在最后一个输出被接收后产生，复位中止尚未交付的输出。

独立覆盖测试以精确 Q4 输入比较有序像素集合。功能模型还提供
Q4_Q16_V1 整机绘制配置，在视口之后量化屏幕坐标并按 RTL 位宽插值。
现有 RTL 的输入端口接收量化后的整数。`flat_draw_compare_test_rtl`
直接用该配置比对附件，覆盖大绝对值 UV 的低位、宽乘积、逐顶点颜色、
深度、混合及遮挡。非网格顶点落点、共享边和深度阈值另有功能模型测试。
[图形数值契约](numerics.md#可选定点配置-q4_q16_v1)列出了所有量化点和饱和域。
