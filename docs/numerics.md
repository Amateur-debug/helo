# 图形数值与跨实现比较契约 v1

本文规定当前浮点参考配置的表示、舍入和比较规则；算法见各模块文档。
Shader机器码的整数、FP32与FCSR语义仍以[ISA](isa.md)为准，不能用本文件的
图形近似误差放宽Shader逐位比较。版本1不引入新的定点光栅算法。

## 表示与执行环境

公共记录定义在[`helo/graphics.h`](../hw/include/helo/graphics.h)，构建要求
IEEE binary32的float及binary64的double，并通过静态断言检查。
固定功能计算的宿主舍入环境要求FE_TONEAREST、渐进下溢；调用者不得启用
flush-to-zero或在执行期间改变浮点环境。模型不修改调用者的舍入模式。
Clang/GCC构建禁用fast-math和隐式乘加收缩；MSVC使用严格浮点模式。
显式Shader FMA仍由SoftFloat按一次舍入执行。

| 阶段边界 | 数值表示、量化与舍入 |
| --- | --- |
| 上传顶点、VS输出 | position/color/uv均为binary32；原始位模式传递 |
| 裁剪 | 平面距离、交点参数和插值表达式使用binary64；每次产生交点转回binary32，并把当前裁剪轴锁定到±w |
| 视口 | 1/w与主要坐标计算使用binary64，输出x/y/z/inv_w转回binary32；深度区间差先按现有float表达式计算 |
| 光栅输入 | 使用上述binary32坐标，不再额外舍入到固定子像素网格 |
| 覆盖与插值 | 边函数、面积、权重和属性累加使用binary64；片元depth/color/uv最终转回binary32 |
| 纹理 | 坐标规约及s/t使用binary64；RGBA归一化、双线性权重和颜色运算使用binary32 |
| ROP | 深度保存binary32且精确比较；混合使用binary32；颜色按下述规则量化为RGBA8，模板为uint8 |

各阶段的显式float转换是量化点。不得任意把中间运算改成定点、FMA或重新
结合加法，再以最终图片“看起来相似”证明等价。算法表达式及求和次序见
[Geom](geom.md)、[Rast](rast.md)、[Tex](tex.md)、[ROP](rop.md)。

## 覆盖、深度与颜色

像素中心为(x+0.5,y+0.5)，屏幕y向下；正面积绕序的内部边函数为正。
边函数等于零时仅包含满足`dy<0 || (dy==0 && dx>0)`的边，不加epsilon。
覆盖集合、共享边归属、discard、深度/模板通过条件均是离散结果，必须一致。
深度在屏幕空间线性插值，不再除透视分母；非有限或超出[0,1]的片元深度丢弃。

颜色先按ROP规则处理NaN/无穷并限幅到[0,1]，再以binary32执行
`floor(c*255.0f+0.5f)`。深度比较、纹理clamp/repeat、模板更新与颜色量化
的边界用例必须精确检查，不能给它们统一加浮点容差。

## 验证比较规则

| 对象 | 通过条件 |
| --- | --- |
| 指令编码、GPR、FCSR、内存字节、模板、命令状态 | 精确一致；显式未规定的执行顺序除外 |
| 覆盖像素坐标与输出顺序 | 精确一致；独立光栅接口按y再x递增，分批不得改变顺序 |
| 固定功能有限浮点属性的独立数学期望 | `abs(actual-expected) <= 1e-5 + 1e-5*abs(expected)`；非有限结果直接失败 |
| RGBA8量化/混合边界、32×32解析组合场景 | 每字节精确一致 |
| 普通GPU行为测试的指定颜色 | 每通道最多1个UNORM码值差；仅用于已有显式标明的颜色断言，不放宽覆盖和深度条件 |
| 同一宿主与编译配置的重构回归 | 完整PNG字节一致或有逐像素差异分析；图片统计不能替代比较 |

浮点容差用于不同算术路径对独立期望的比较，不改变模型运算或决定覆盖。
接近离散阈值时，应单独构造明确期望的边界测试。随机测试固定种子并输出
用例序号；失败可按种子和序号复现。不要通过扩大通用容差隐藏失败。

## 未来定点RTL的接入条件

当前契约的坐标量化明确为binary32，无隐藏的“默认8位子像素”。定点RTL若
不能复现本配置，必须新增具名、带版本的数值配置，明确坐标小数位、范围、
每级舍入/饱和、插值与纹理误差，再让参考模型与测试选择同一配置。
禁止对任意边缘像素直接豁免比较，也不能用颜色容差掩盖深度通过条件变化。
本次实现的固定种子共享边测试使用1/16网格，并验证两种对角线、反向绕序和
屏幕裁界；它是当前配置的确定性测试域。

### Q4 覆盖输入域 v1

`RAST_COVERAGE_GRID_Q4_V1`是独立的覆盖单元输入配置，不修改上述整机
binary32数值配置：屏幕x/y在[-32768,32767.9375]，均为1/16像素
的整数倍；目标宽高为16位无符号数。Q4整数到binary32的转换精确，
当前测试以相同整数构造参考模型ScreenTriangle，显式选择此输入域。
边值/面积为Q8带符号计算、64位承载；给定域内交叉积小于binary64精确
整数范围，因此C++ Rast的double边判定与RTL边判定逐像素一致。
包围盒负值按数学floor/ceil处理，不饱和输入坐标；目标外候选裁界。
输出边值不转换float，不含插值、纹理或颜色误差承诺。完整Geom接线前
必须将量化点及属性计算扩展为新的整机数值配置，不能把非网格输入
偷偷截断后套用本覆盖域的验证结论。

### 受限绘制Q16属性域

`helo_flat_draw`在上述Q4覆盖输入域之上接受可选Q16顶点窗口深度
`[0,65536]`，按整数边值加权、半值向上舍入到Q16，再精确编码为
binary32。可选逐顶点有符号Q16 UV及正的Q16倒数w`[1,65536]`：
`round_away_from_zero(Σ(edge*inv_w*uv)/Σ(edge*inv_w))`，结果保留Q16。
负面积图元同步交换顶点1/2及其属性。固定UV也可直接提供有符号Q16值。
逐顶点RGBA8颜色可使用同一透视权重逐通道插值、半值向上舍入到RGBA8；
也可使用平面RGBA8。纹理采用最近点RGBA8，各轴独立clamp/repeat；颜色与纹素
逐字节相乘以`(a*b+127)/255`舍入，再由ROP执行打包RGBA8混色。
这不是上文FP32整机数值契约的替代：特别是FP32颜色、任意FP32顶点坐标、
双线性过滤和Shader仍需另行实现与验证。该受限域的差分测试先将
C++ Rast插值结果量化到Q16，再与C++ Tex/ROP的离散像素对比。
